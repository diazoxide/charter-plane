r/ClaudeAI's showcase rule governs a project post (rule priority 6 in the rules JSON as read 2026-08-14; the reddit persona text calls it rule 7): the project must be built with Claude or Claude Code BY YOU, the post must state what was built, how Claude helped and what it does, must say it is free to try (paid tiers OK), keep promotional language minimal, and use no referral links (a plain project link is fine). Posts require OP karma > 50. The 'Built with Claude' flair does NOT require a prompt; that secondary-source claim was checked against the rules, sidebar, submit_text, widgets and AutoMod and refuted. Disclose that you built it in the post itself: undisclosed ownership ('stealth ad') is what actually sinks a post. Re-read the rules before each post; they change.
