# Escaping text at one surface proves nothing about the others; ask wher

_2026-09-25 · persistent_

Escaping text at one surface proves nothing about the others; ask where else the same bytes reach a terminal or a screen. Measured 2026-09-12: a mutation run flagged one line that escaped a brief into a notice, and asking the class question instead of fixing the line found three more surfaces carrying the same attacker-influenced bytes raw, including a refusal the operator was told to paste into a terminal (shell single-quoting escapes nothing, so ESC, backspace and bidi controls pass through, and a leading carriage return can repaint a refusal as success). Surfaces that cannot be driven in a test are reported as unmeasured, not assumed safe. A renderer is where untrusted text must be escaped, never on the way into storage, which would corrupt the file a person reads. In charter-app this covers every place plane text (brief, todo, workspace name, memory) reaches a terminal pane, a notification or the webview.
