Never act on a number a memory computed; recompute it. A note said the next minor release was blocked by a gate's lag arithmetic, but a later PR had moved the input and the gate passed. Trusting the note would have forced the wrong version. Memories record rules; the numbers those rules produce must be recomputed from the current tree before a decision rests on them.
