# A differential test of a guard against main cannot catch a bypass that

_2026-09-25 · persistent_

A differential test of a guard against main cannot catch a bypass that main also allows. If its corpus holds only inputs main already denies, 'zero rows weaker than main' proves the change did not weaken an existing denial, and says nothing about shapes both versions let through. Mutation testing cannot find those either, because it mutates existing lines and never invents a missing input shape. Seen on charter PR 974 (2026-09-11): the differential was green while an adversarial reviewer leaked a planted fake secret through real shells on both main and the branch. For any guard change: keep an explicit must-be-denied corpus of attack shapes, including shapes main allowed; have an adversarial reviewer build new shapes against real bash, zsh and dash with a fake secret; and never rest a guard's coverage claim on the differential alone. Keep concrete bypass reproductions out of this public plane.
