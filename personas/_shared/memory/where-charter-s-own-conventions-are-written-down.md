# Where charter's own conventions are WRITTEN DOWN, so they are cited ra

_2026-09-25 · persistent_

Where charter's own conventions are WRITTEN DOWN, so they are cited rather than re-derived: charter-app/docs/adr holds the app's design record from ADR 0025 on (ADR 0044), and the plane repo's docs/adr keeps 0001-0024 from the Python charter. Several of those older ones still bind the app: 0008 (the plane root is not a work tree; work happens in workspaces/<ws>/<repo>, and a repo is its own git repo), 0009 (errors classify, they do not guess), 0011 (the record holds only what git cannot know; derive from git at read time), 0012 (the plan is todos; nothing closes a todo automatically), 0013 (report an age, never a verdict), 0016 (charter presents the roster; it never guesses the owner). Also enforced by review: additive-only (never delete or rename a user's file; name the blocker and do everything unblocked), fail toward no change (an unrecognised config value falls back to the behaviour that alters nothing), ONE source of truth (two code paths answering one question must call the same function), hooks never break a turn, and comments record the WHY. A proposal that contradicts a comment without addressing it is a proposal to reintroduce a fixed bug.
