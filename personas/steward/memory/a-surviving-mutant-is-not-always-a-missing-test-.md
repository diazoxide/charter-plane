# A surviving mutant is not always a missing test — sometimes a REDUNDANT

_2026-09-22 13:26 · persistent_

A surviving mutant is not always a missing test — sometimes a REDUNDANT GUARD is absorbing it, and then no test could ever kill it. charter-app pypath::realpath had three MISSED mutants (> to >=, -= to +=, -= to /= on the loop counter). None is a no-op: each stops the loop from terminating on part_count. They survived because 'let Some(x) = rest.pop() else { break }' was a SECOND, silent stop condition that caught the overrun and returned the same answer. 540,000 generated symlink farms: zero divergences for all three, 54,004 for a control mutation — so they were provably unkillable as written. Fix: state the invariant the code already relies on (debug_assert!(!rest.is_empty())) instead of papering over it; all three then die on the first call. Before 3 missed / 9 caught, after 0 missed / 12 caught. Use debug_assert and NOT expect in charter's guards: a panic in pretooluse exits 1 and a harness reads that as ALLOW, so a crash is fail-OPEN. Method that settled it: build a probe with all variants plus a POSITIVE CONTROL mutation known to be real — a sweep that finds nothing proves nothing unless the control fires.
