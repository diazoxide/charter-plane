_2026-09-21 04:04 · persistent_

Mutation testing on a differential port pays twice if you run each mutant against BOTH the fuzz and the checked-in corpus separately. charter-app M3.1 stage 2: 55 mutations, none inert, but twelve rules the 3000-case fuzz saw the 162-row recording did not — which is a rule with no test the day the fuzz is trimmed. The nine the fuzz alone cannot reach were all CPython-vs-Rust facts (\d is \p{Nd} not [0-9]; CPython's $ matches before a trailing newline; git's --edit long spellings) reachable only through quoted tokens. Also: mutate a WHOLE function, not one of its returns — breaking only pipeline_slice's final return read as 15/0 'thin rule', breaking the function read 1399/58.
