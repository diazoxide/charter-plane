# Codex CLI 0.147.0's hook system is Claude Code's contract near-verbati

_2026-09-25 · persistent_

Codex CLI 0.147.0's hook system is Claude Code's contract near-verbatim, extracted from the draft-07 JSON schema embedded in the binary (strings ~/.codex/packages/standalone/releases/<ver>/bin/codex, search '"hook_event_name"'). Events: PreToolUse, PermissionRequest, PostToolUse, PreCompact, PostCompact, SessionStart, SessionEnd, UserPromptSubmit, SubagentStart, SubagentStop, Stop. PostToolUse input has Claude Code's field names plus turn_id/agent_id/agent_type. Output: hookSpecificOutput{hookEventName, additionalContext, permissionDecision, permissionDecisionReason, updatedInput, updatedPermissions} plus continue/stopReason/suppressOutput/systemMessage. Hooks carry a trust model (matcher/hooks/enabled/trusted_hash; --dangerously-bypass-hook-trust exists). Env injection point is shell_environment_policy.set. Codex also has a status line (status_line, status_line_use_colors; /statusline). So charter-app's hook wiring can target Codex with one adapter rather than a separate guard implementation.
