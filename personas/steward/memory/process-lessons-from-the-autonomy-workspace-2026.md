Process lessons earned 2026-08-19/20 (four releases in one day). (1) Batch releases: cutting one release per fix made every verification pass shallower, and one shipped broken, caught only by a smoke test nearly skipped because unit tests were green. One careful release beats several hurried ones. (2) Dispatch release work to the release persona instead of doing it as steward; that persona holds the knowledge that bites. (3) Watch for workspace drift: a workspace that absorbs unrelated features, flaky-test fixes and gaps stops telling a fork what the work is. Open a new workspace when the causal chain leaves the workspace's charter. (4) But keep a genuine causal chain in one session: a finding that is only visible because the context holds WHY an earlier decision was made should stay there. Split by subject, not by order of discovery.
