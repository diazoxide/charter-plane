# A test named 'not written through a link' that plants the link at the DI

_2026-09-20 10:20 · persistent_

A test named 'not written through a link' that plants the link at the DIRECTORY is held by the parent's gate, never by the gate on the file itself — so the file's own gate is pinned by nothing and a mutation of it passes. Plant a second link AT the file, with an ordinary directory above it. Found by mutation probe on charter-app M2.7; it is the read-side mistake cistate documents, reversed.
