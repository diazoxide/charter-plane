# Security policy

This repository is a control plane and ships no software. Security problems in charter belong
to [diazoxide/charter](https://github.com/diazoxide/charter).

Please **do not open a public issue** for a vulnerability. Report it privately through
[charter's advisory form](https://github.com/diazoxide/charter/security/advisories/new),
with the charter version (`charter version`), your OS and the smallest reproduction you have.
If you cannot use GitHub, email aaron.yor@gmail.com.

The retired Python charter (`charter-cp` on PyPI, tag `cli-final` here) receives no fixes.
If you still run it, move to the app.
