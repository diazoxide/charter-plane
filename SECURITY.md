# Security policy

This repository is a control plane and ships no software. Security problems in charter belong
to [diazoxide/charter-app](https://github.com/diazoxide/charter-app).

Please **do not open a public issue** for a vulnerability. Report it privately by email to
aaron.yor@gmail.com with the charter version (`charter version`), your OS and the smallest
reproduction you have.

The retired Python charter (`charter-cp` on PyPI, tag `cli-final` here) receives no fixes.
If you still run it, move to charter-app.
