charter is now a desktop app: https://github.com/diazoxide/charter/releases. This
package, `charter-cp`, gets no further releases. 0.62.2 stops it from pointing at places that
now mean something else.

The GitHub repository this package came from was renamed `diazoxide/charter-plane`, and the
desktop app's repository took over the name `diazoxide/charter`. Up to 0.62.1, charter-cp
named `diazoxide/charter` in five places meaning *this package*, and every one of them now
reaches the app instead:

- **`charter update` installs nothing.** It prints that charter-cp is no longer maintained,
  names the app's releases page, and exits 0. On the dev channel it used to install
  `git+https://github.com/diazoxide/charter@main`. That install path is gone.
- **The update check is off.** The status line, the frame and session start no longer start
  a background check, and neither channel reports a newer charter. The dev channel no longer
  reads the head of `main` on GitHub.
- **`charter report send` files on `diazoxide/charter`, the app,** on purpose: charter-cp
  takes no more fixes, and the plane repository takes no reports. `$CHARTER_UPSTREAM_REPO`
  still overrides it.
- **The plugin marketplace is `diazoxide/charter-plane`.** `charter init` and `charter
  doctor --fix` pass it to `claude plugin marketplace add`, and the Codex wiring prints it.
  That repository's `main` holds no plugin any more, so on a machine that does not already
  have charter's marketplace, adding it fails and charter reports the failure. It does not
  install something that is not charter.
- **The package metadata** points at `diazoxide/charter-plane` for the source, and at the
  app's releases page and issue tracker for the home page and issues.

`charter --version` and `charter update` print the notice every time. Other commands print it
once per run, and only when stderr is a terminal, so hooks, the status line, the frame and a
chat's shell calls see no change in their output. Nothing is uninstalled, and existing planes
keep working as they did on 0.62.1.

0.62.2 is a patch on 0.62.1 and carries nothing else.
