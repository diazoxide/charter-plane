# Decision records

These are the decision records written while charter lived in this repository.

- **0001–0024** belong to the Python charter. They are history, and several still bind
  charter-app, which cites them here at a fixed commit.
- **0025–0042** were moved to charter-app by its ADR 0044, which is where they are amended.
  The copies here are the record of where they were first written; if the two differ,
  [charter-app's](https://github.com/diazoxide/charter-app/tree/main/docs/adr) are right.

Nothing new is recorded here. The numbering continues in charter-app, and every charter
decision is written there.

This repository became a plane repo on 2026-09-25: the Python charter left the tree at tag
`cli-final`, and everything that remained describes this plane, not the software.
